# OCBC Steady

**2nd place, Intelligent Banking (OCBC) category, PolyFinTech100 API Hackathon 2026** (team of 5)

An AI agent that turns gig workers' uneven earnings into a fixed weekly salary. As earnings land, it allocates every dollar down a fixed ladder: CPF and tax set-asides, then bills, then a weekly "Steady Salary", then a 4-week buffer, then savings goals. The worker sets the limits Steady works within.

- `index.html`: interactive web prototype with a live allocation engine and user-set controls. Open it in any browser.
- `ocbc-steady-prototype.jsx`: React version of the prototype
- `docs/`: pitch deck, proposal and video script

The design is grounded in Singapore rules: CPF, the Platform Workers Act, PDPA and MAS licensing.
